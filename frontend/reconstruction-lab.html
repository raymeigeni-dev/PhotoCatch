3. 手动运行

Apple Object Capture

Mac 原生 RealityKit 摄影测量，输出 USDZ。不需要 NVIDIA CUDA；需要先编译原生 helper，且素材需满足重建条件。

POST /api/video/reconstruct/apple

COLMAP / OpenMVS

运行已有的多视角重建入口；在没有 CUDA 的 Mac 上，只有 OpenMVS CPU 工具实际可用时才可能完成稠密重建。

POST /api/video/reconstruct

云端网关

仅在你配置了云端 HTTP 网关及凭据后可用。当前代码是适配器，不是开箱即用的 RealityCapture 连接。

POST /api/video/reconstruct/cloud
